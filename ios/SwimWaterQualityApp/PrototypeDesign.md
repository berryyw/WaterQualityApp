# 泳池水质通苹果风格原型设计

## 1. 视觉方向

- 设计风格：`iOS 27.0` 原生感、清透蓝色系、强调地图和内容卡片的层次融合
- 关键词：可信、清澈、专业、现代、克制
- 背景建议：`systemGroupedBackground`
- 卡片建议：`secondarySystemBackground`、大圆角、轻描边、薄材质阴影
- 主色建议：蓝色渐变，重点区域使用更浅的水蓝高光
- 图标风格：优先使用简洁的水滴、波浪、定位、列表与账号类 `SF Symbols`

## 2. 导航结构

- 登录前：欢迎页、邮箱登录 / 注册页、验证码页、设置密码页、密码登录页
- 登录后 Tab 1：地图
- 登录后 Tab 2：热度
- 登录后 Tab 3：我的

## 3. 登录与注册原型

### 欢迎页

- App 名称
- 一句价值主张：`附近泳馆，水质一眼可见`
- 主按钮：邮箱注册 / 登录

### 邮箱登录 / 注册页

- 邮箱输入框
- 发送验证码按钮
- 次要说明文案：验证码将发送到邮箱

### 验证码页

- 邮箱回显
- 6 位验证码输入框
- 倒计时和重新发送入口
- 主按钮：验证并继续

### 设置密码页

- 新密码输入框
- 确认密码输入框
- 密码要求说明：`8-20` 位，至少包含字母和数字
- 主按钮：完成设置

### 密码登录页

- 邮箱输入框
- 密码输入框
- 登录按钮
- 辅助入口：忘记密码

### 修改邮箱 / 修改密码验证页

- 展示当前操作类型
- 向目标邮箱发送验证码
- 6 位验证码输入框
- 验证通过后进入下一步修改表单

## 4. 地图页原型

### 顶部

- 左侧或中部显示当前城市，默认 `北京`
- 城市切换入口
- 搜索框：搜索泳馆名称

### 地图内容区

- 地图底层调用 `Apple Map / MapKit`
- 地图上标记游泳馆位置和名称
- 标注样式建议为：品牌色气泡 + 泳馆名称短标签
- 当前定位入口

### 页面交互

- 点击搜索框进入搜索态，搜索结果列表可直接跳转详情页
- 点击地图上的某个泳馆标注，进入详情页
- 从详情页可返回上一页

## 5. 泳馆详情页原型

### 头部区域

- 返回按钮
- 游泳馆名称
- 场馆主图
- 地址位置
- 坐标信息
- 主按钮：关注 / 取消关注

### 基础信息卡片

- 名称
- 图片
- 地址位置
- 坐标

### 水质信息卡片

- 分区方式建议为四组：
- 物理性指标：浑浊度、水温
- 化学性指标：`PH`、游离性余氯、化合性余氯、`ORP`
- 微生物指标：菌落总数、总大肠菌群
- 其他指标：尿素、氰尿酸、`TDS`
- 最近更新时间

### 用户评价卡片

- 用户头像
- 用户名称
- 评价内容
- 评价时间
- 列表式排列，支持连续浏览

## 6. 热度页原型

- 页面标题：`热度`
- 列表排序逻辑：同城内按关注人数从高到低
- 每个列表项展示：
- 游泳馆图片
- 游泳馆名称
- 关注人数总数
- 可选标签：热门、近期上升、学生常去
- 点击某一行进入泳馆详情页

## 7. 我的页原型

- 头部用户卡片
- 用户头像
- 用户昵称
- 用户邮箱
- 列表入口：我的关注

### 页面交互

- 点击头像：上传或更换头像
- 点击昵称：进入昵称编辑页并保存
- 点击“我的关注”：进入关注列表页
- 点击邮箱或安全设置项：进入修改邮箱或修改密码流程，并触发验证码校验

## 8. 我的关注页原型

- 列表展示已关注泳馆
- 每项展示：
- 泳馆图片
- 泳馆名称
- 关注人数总数
- 城市或区域辅助信息
- 点击某一行进入泳馆详情页

## 9. 城市切换原型

- 入口位置：地图页顶部
- 选择方式：系统风格列表页，支持搜索城市
- 默认城市：北京
- 扩展方向：全国主要城市逐步开放

## 10. 苹果风格细节

- 导航栏优先使用大标题与材质背景组合
- 主按钮使用更接近系统的 `borderedProminent` 或自定义玻璃感按钮
- 输入页保持简洁纵向布局，减少干扰项
- 列表页采用卡片化分组，避免传统表格感过强
- 详情页按“基础信息 -> 水质信息 -> 用户评价”顺序组织，降低阅读负担
