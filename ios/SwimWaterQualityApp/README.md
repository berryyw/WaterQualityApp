# SwimWaterQualityApp

这是一个独立的 `SwiftUI` iOS 项目，产品方向聚焦“附近游泳馆水质信息查询”。  
新一版产品范围按全国城市架构设计，默认城市为北京，登录后采用三个底部 Tab：`地图`、`热度`、`我的`。

当前仓库中的代码是原型基础版本；本 README 已按最新需求更新为下一阶段的正式产品说明，用于后续设计、开发和联调对齐。

## 产品目标

- 帮助用户快速找到附近泳馆，并在出发前判断水质是否值得去
- 将地图找馆、水质指标、用户评价、热度排序和我的关注统一到一个 App 内
- 支持从北京起步，后续扩展到全国更多城市

## 最新功能范围

### 账号体系

- 支持邮箱注册
- 系统向邮箱发送验证码
- 用户使用邮箱 + 验证码完成首次登录
- 首次登录后设置密码
- 后续支持邮箱 + 密码登录
- 验证码仅用于首次登录，以及修改邮箱、修改密码时的安全校验
- 密码规则固定为 `8-20` 位，且至少包含字母和数字

### Tab 结构

- `地图`
- `热度`
- `我的`

### 地图

- 底层地图服务使用 `Apple Map / MapKit`
- 地图上展示游泳馆位置和名称
- 顶部提供搜索框，支持按泳馆名称搜索
- 用户点击搜索结果进入泳馆详情页
- 用户点击地图标注也可进入泳馆详情页
- 详情页支持返回上一页

### 泳馆详情

- 支持关注 / 取消关注
- 包含三部分信息：
- 第一部分为基础信息：名称、图片、地址位置、坐标
- 第二部分为水质信息：浑浊度、水温、`PH`、游离性余氯、化合性余氯、`ORP`、菌落总数、总大肠菌群、尿素、氰尿酸、`TDS`、更新时间
- 第三部分为用户评价：用户图片、用户名称、评价内容、评价时间

### 热度

- 展示当前城市内按关注人数从高到低排序的游泳馆列表
- 列表展示泳馆图片、名称、关注人数总数
- 点击列表任一泳馆可进入详情页

### 我的

- 展示用户头像、昵称、邮箱和“我的关注”
- 点击头像可上传或更换头像
- 点击昵称可编辑并保存昵称
- 点击“我的关注”可查看已关注泳馆列表

### 我的关注

- 列表展示泳馆图片、名称、关注人数总数
- 点击任一泳馆可进入详情页
